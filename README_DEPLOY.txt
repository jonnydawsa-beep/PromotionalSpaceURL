AWIN PROMOTIONAL SITE STARTER
============================

PURPOSE
-------
This is a real, public-facing pre-launch landing site for the product-comparison project.
It accurately says the service is in development. It does not invent traffic, prices,
retailer partnerships, users or approval that does not yet exist.

BEFORE SUBMITTING TO AWIN
-------------------------
1. Upload these site files to a PUBLIC HTTPS URL that you control.
2. Open the URL in a private/incognito browser and check:
   - home page loads
   - About loads
   - Advertising disclosure loads
   - Privacy loads
   - no login is required
3. Use that exact public URL as the "Promotional Space URL" in Awin.
4. Keep the site live while Awin reviews the application.

EASIEST FREE HOSTING OPTIONS
----------------------------
A) GitHub Pages
   - Create a public repository.
   - Upload index.html, about.html, affiliate-disclosure.html, privacy.html,
     styles.css and robots.txt to the repository root.
   - In GitHub: Settings -> Pages -> Deploy from a branch -> main / root.
   - GitHub will provide an HTTPS public URL.

B) Cloudflare Pages / similar static hosting
   - Create a Pages project.
   - Upload/deploy the contents of this folder.
   - Use the public HTTPS URL supplied by the host.

WHAT TO PUT INTO AWIN
---------------------
Promotional Type:
  Comparison Engine

Description (fits the 255-character field):
  UK product comparison site in development. We compare identical products across
  approved retailers, identify meaningful price differences and direct users to
  retailers through clearly disclosed affiliate links.

Sector:
  Retail & Shopping. Select only subcategories you genuinely expect to cover.
  Good initial choices, IF they exist in Awin's list:
  - Consumer Electronics / Electricals
  - Home & Garden
  - DIY / Tools
  - Toys / Games / Hobbies

DO NOT CLAIM
------------
- existing traffic if there isn't any
- retailer approval before approval
- live prices before the feed is running
- "independent" in a way that hides affiliate incentives
- guaranteed cheapest prices

AFFILIATE DISCLOSURE
--------------------
Once actual affiliate offers are published, each affiliate-linked offer/content
must be made obviously identifiable as advertising at the point users encounter it.
The starter disclosure page is useful context but is not a substitute for clear
labels on live affiliate content.

IMPORTANT
---------
This starter deliberately uses no analytics, cookies, contact form or external
scripts. If those are added later, review/update the privacy and cookie position
before deployment.
